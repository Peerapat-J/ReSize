# ตรวจด้วยตนเอง

ใช้ `swift scripts/make-fixtures.swift` สร้าง `sample-4k.png` และ `sample-small.png` ใน `/private/tmp/resize-fixtures` ก่อนเริ่ม แต่ควรลอง screenshot จริงของแอปด้วย

## รายการตรวจ

1. เปิด PNG/JPEG จากปุ่ม Open และลากจาก Finder ได้ ลองเปิดหลายภาพพร้อมกัน
2. เลือก Crop Only 2880 × 1800 บนภาพ 4K กรอบเริ่มกึ่งกลางที่ x=480, y=180
3. ลากกรอบไปทุกขอบ กรอบอยู่ในภาพและขนาดคงเดิม ใช้ลูกศร/Shift+ลูกศรขยับ 1/10 px
4. สลับ Fit to Window/50%/100%/200% ตำแหน่ง crop ไม่เปลี่ยน เลื่อนภาพที่ใหญ่กว่า viewport ได้
5. สลับ Source/Output ภาพที่เห็นตรงกับพื้นที่ในกรอบ รวมถึงเมื่อเลื่อนกรอบชิดขอบ
6. Crop & Resize ลากทั้งสี่มุมได้ สัดส่วนคงเดิม Center/Reset ทำงาน และระบุ upscaling เมื่อมีการขยาย
7. Fit เห็นครบทุกมุม เปลี่ยนสีพื้นหลังแล้วพื้นที่ว่างและพื้นที่โปร่งใสเปลี่ยนตาม
8. Custom แก้ width/height เลือก ratio และล็อกอัตราส่วนได้ ค่า 0/เกินขีดจำกัดแสดงคำอธิบายและส่งออกไม่ได้
9. ภาพเล็กใช้ Crop Only ที่ใหญ่เกินไปไม่ได้ เปลี่ยนไป Fit หรือ Custom ที่เล็กลงแล้วใช้ได้
10. เลือก JPEG เปลี่ยน quality แล้วดู Output/file size; เปลี่ยน PNG แล้วไม่มี quality slider
11. Export ภาพเดียว เลือกโฟลเดอร์ เปิดไฟล์จริง ตรวจขนาด รูปแบบ RGB/alpha และสีใน Preview.app
12. เลือกหลายภาพ ใช้ Apply Settings แล้ว crop ของแต่ละใบยังแยกกัน สลับใบแล้วค่าถูกต้อง
13. Export All มีรายงานสำเร็จ/ล้มเหลว ส่งออกซ้ำแล้วเพิ่มเลข ไฟล์เก่าและต้นฉบับไม่เปลี่ยน
14. Cancel ระหว่าง batch เก็บไฟล์ที่เสร็จแล้ว ไม่มีไฟล์ปลายทางครึ่งหนึ่งหรือ temporary file ค้าง
15. ลองไฟล์เสีย ไฟล์ที่ถูกแก้หลังเปิด และโฟลเดอร์ที่เขียนไม่ได้ ต้องแสดงข้อผิดพลาดโดยแอปยังใช้งานต่อได้
16. เปิด/ปิดกล่องเลือกไฟล์ด้วย mouse/⌘O ซ้ำ ๆ ไม่มีกล่องซ้อนกัน
17. ลองใช้คีย์บอร์ดและ VoiceOver ตรวจ label/focus และทดลองอีกครั้งบนจอที่มี backing scale ต่างกัน

## สถานะการตรวจ

ตรวจเมื่อ 2 กันยายน 2026 บน macOS 26.6.2 / Xcode 26.6 (Apple Silicon)

### Automated

- Core/IO tests: **19 ผ่าน, 0 ล้มเหลว**
- Debug และ Release build: ผ่าน
- SwiftLint ตามกฎของ repository: ผ่าน
- `git diff --check`: ผ่าน
- ตรวจไฟล์ที่ GUI ส่งออกด้วย `sips`: PNG/JPEG เป็น 2880 × 1800, ไม่มี alpha, profile sRGB IEC61966-2.1

### GUI ที่ลองจริง

- เปิดหน้าต่างและนำเข้าสองไฟล์จาก Open panel
- Crop Only กึ่งกลาง, ลากกรอบ, ปุ่มลูกศร และสลับ Output ตรงกับกรอบ
- ภาพ 1200 × 800 ถูกบล็อกเมื่อ Crop Only ใหญ่เกินไป; เปลี่ยน Fit แล้วส่งออกได้
- Fit เก็บครบทั้งสี่มุมและเพิ่มพื้นที่สีขาวด้านข้าง
- เปลี่ยน PNG/JPEG และแสดงตัวเลือก JPEG quality
- สลับภาพแล้ว mode/format ของแต่ละภาพยังอยู่
- Crop & Resize ลากมุมขวาล่างแล้วสัดส่วนคงเดิม
- เปลี่ยน zoom เป็น 100% และ scroll โดยตำแหน่ง crop ไม่เปลี่ยน
- Custom lock 16:10: กรอก 1920 แล้วได้ 1200; กรอก 0 แล้วบล็อก Export; กลับเป็น 1920 แล้วใช้งานต่อได้
- Export ภาพเดียว: 1 สำเร็จ, 0 ล้มเหลว
- Export All: 2 สำเร็จ, 0 ล้มเหลว (หนึ่ง PNG และหนึ่ง JPEG); ชื่อซ้ำได้ `.2.png` โดยไฟล์เดิมยังอยู่
- กล่อง Open/Save ใช้ sheet ที่ผูกกับหน้าต่างหลัก
- รอบปรับสี: Source/Output, PNG/JPEG, Export, Center/Reset และ Crop area slider เป็นสีน้ำเงินตามค่า Accent ของเครื่อง
- ไอคอนขาว–เทาเรนเดอร์ครบทุกขนาด ตรวจไฟล์ 16 px และ 1024 px ว่ามีพื้นหลังโปร่งใสรอบไอคอน; build Debug/Release และ lint ผ่านหลังปรับสี
- หลังเปลี่ยนชื่อเป็น ReSize: build Debug/Release และ tests 19 รายการผ่าน เปิดแอปแล้วชื่อหน้าต่างและเมนูเป็น ReSize

### ยังไม่ได้ลองด้วยตนเอง

- ลากไฟล์จาก Finder, Apply Settings กับหลายรายการ และเปิดไฟล์ผ่าน Finder โดยตรง
- ลาก crop ให้ครบทั้งสี่มุม, Shift+ลูกศร, zoom 50%/200% และสีพื้นหลังอื่นใน GUI
- กด Cancel ระหว่าง batch ยาว ๆ และกรณี permission denied ใน GUI (cancellation/file collision มี automated tests)
- ภาพ P3/HDR/16-bit และเทียบสี/ความอ่านง่ายกับ screenshot จริงของแอปผู้ใช้
- VoiceOver เต็ม flow, Light Mode และหลายจอที่มี backing scale ต่างกัน
- เปลี่ยน Accent ของ macOS เป็นสีอื่นขณะแอปเปิดอยู่
- macOS 14/15 runtime และการติดตั้งแบบแจกจ่าย

การผ่าน build และ tests บนเครื่องนี้ไม่ใช้แทน runtime QA บน macOS รุ่นอื่น
